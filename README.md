# AlgoFin

Aplicativo educacional de Matemática Financeira com Pensamento Computacional para os anos finais do Ensino Fundamental, produto da dissertação de mestrado de Alberto Nairo Silva de Araújo (IMECC/Unicamp, 2026).

- `AlgoFin/`: código-fonte do aplicativo (instruções em `AlgoFin/README.md`).
- `conferencia/`: scripts e resultados da conferência dos cálculos (Apêndice B da dissertação), inclusive o teste que compara as tabelas do aplicativo com a referência exata (`test_modelo_app.py`).
